# External satellite data

This directory is intentionally empty of runtime assets in Git. A clone cannot classify crops until data and a compatible model are provisioned.

See [asset provisioning and directory contracts](../docs/ASSETS.md). Use `prepare_data.py` for PASTIS or `prepare_cog.py`/`prepare_regions.py` for continuous COG data. Catalogs, arrays, masks, predictions, results and download caches remain untracked.
